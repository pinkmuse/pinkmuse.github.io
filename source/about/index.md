### 协作方式

本站基于 [Hexo](https://hexo.io/) 构建，托管于 [GitHub Pages](https://pages.github.com/)。

**方式一：直接在网页上编辑**

1. 打开 [博客仓库](https://github.com/pinkmuse/pinkmuse.github.io)
2. 进入 source/_posts/ 文件夹
3. 点击「Add file」→「Create new file」
4. 命名文件，粘贴 [文章模板](https://github.com/pinkmuse/pinkmuse.github.io/blob/main/source/_TEMPLATE.md) 内容并修改
5. 点击「Commit changes」提交
6. 等待几分钟，文章自动发布

**方式二：Git 本地工作流（适合熟悉 Git 的协作者）**

1. Fork 或克隆仓库：git clone https://github.com/pinkmuse/pinkmuse.github.io.git
2. 创建文章：
px hexo new "文章标题"
3. 编辑 source/_posts/ 下的 Markdown 文件
4. 提交 PR 或直接推送到 main 分支
5. CI 自动构建部署
